# Mockups

Tauri 2 + Rust + React/TypeScript töölauarakendus: pliiatsiga joonistamise lõuend vasakul ja päris terminal paremal.

## Käivitamine (Windows)

1. Paigalda [Rust (rustup)](https://rustup.rs/), Node.js, Microsoft C++ Build Tools ning WebView2 (Windows 11-s enamasti juba olemas). Taaskäivita terminal, et `cargo` oleks PATH-is.
2. Käivita projekti juures `npm install` ja `npm run tauri dev`. Kui käsureal kasutatakse Git Bashi `link.exe`-d või MSVC linker pole PATH-is, käivita hoopis `start-dev.cmd` (seab Visual Studio 2022 Build Toolsi keskkonna).
3. Produktsioonipaketi jaoks: `npm run tauri build` Visual Studio Developer Command Promptist.

`npm run dev` avab ainult veebiliidese eelvaate: selles pole päris terminali ega failide automaatsalvestust.

## Kasutamine

- Joonista pliiatsi, hiire või puutega. Tööriistad: valik, pliiats, marker, kustukumm, joon, ristkülik ja ellips. Lõuendit saab endiselt lohistada hiire keskmise nupuga. Neli esimest tööriista saab valida klahvidega **1** (valik), **2** (pliiats), **3** (marker), **4** (kustukumm). Kolme väikese ikoonlüliti klahvid on **Q** (Automaatkujud), **W** (Autosnap) ja **E** (Ainult pliiats). Klahvid kuvatakse ka hiirega nuppude kohal; tagasi/edasi Ctrl+Z / Ctrl+Y.
- **Automaatkujud** (kujundite ikoon tööriistaribal) on vaikimisi sees. Joonista pliiatsiga ühes tõmbes sirge, ristkülik, ellips või kolmnurk: pliiatsi tõstmisel muutub piisavalt sarnane visand korrapäraseks kujundiks. Lülita nupp välja vabakäejoone säilitamiseks. Seade jääb selle arvuti rakenduses meelde; kui avatud tõmme pole äratuntav kujund, muutub see sirgeks jooneks oma algusest lõpuni. Täpp ja tundmatu suletud silmus ei muutu väikeseks jooneks. Vabakäejoone jaoks lülita Automaatkujud välja. Tagasivõtmine eemaldab kogu tõmbe.
- **Impordi pilt** ikoonnupp või pildifaili lõuendile lohistamine lisab PNG/JPG/WebP pildi (kuni 8 MB ja 40 miljonit pikslit). Pilti saab valida, liigutada, venitada, lukustada ja kopeerida. Andmed salvestuvad projektiga. Claude saab kohaliku kuvatõmmise lisada `import-image` käsuga (vt `AGENT-API.md`); veebilehe kuvatõmmise tegemiseks peab tal olema brauseritööriist.
- **Valmiskujundid** rippmenüü tööriistaribal lisab aktiivsele lehele läbipaistva brauseriakna aluse (ainult raam, vaheleht, aadressiriba ja jooned; selle alla jäävad joonised paistavad läbi), käesoleva kuu kalendri, sisselogimisvormi, sisukaardi, otsinguvälja, profiiliikooni, valikukasti, nupu, tekstivälja, märkeruudu, lüliti või päiseriba. Iga lisatud komponent on grupeeritud: klõps valib kogu komponendi, lohistamine liigutab seda, Delete eemaldab ja Ctrl+Z võtab lisamise ühe sammuga tagasi. Valitud joonise või grupi saab Ctrl+D abil kohe duplitseerida; Ctrl+C ja Ctrl+V kopeerivad ning kleebivad objekte ka erinevate lehtede vahel. Koopial on iseseisvad jooned ja grupid. Valmisvormi esimene klõps valib kogu vormi; järgmine klõps juba valitud vormi sees valib ühe elemendi, mida saab eraldi liigutada või kustutada (lohista aga tervet valitud vormi endiselt koos). Alt+klõps valib kohe ühe elemendi. Ctrl+Shift+G eemaldab soovi korral grupi jäädavalt. Valitud joonise või grupi saab valimistööriista kõrval oleva lukuikooniga lukustada ja sama nupuga taas avada. Lukus objekte ei saa liigutada, muuta, kustutada ega kustukummiga eemaldada; lõuendi tühjendamine jätab need alles. Valitud lukustamata objekti külgede ja nurkade käepidemed muudavad selle mõõtmeid; jaluse L/K väljad lubavad täpse laiuse/kõrguse sisestada (Enter). Brauserialuse alumisest servast venitamine pikendab üksnes lehe ala. Lõuend on piiramatu: ühe sõrmega saab seda liigutada, kahe sõrmega puuteekraanil või puuteplaadi näpistusega suumida; puutepliiats jääb joonistamiseks. Hiireratas ja puuteplaadi kerimine liigutavad vaadet, Ctrl+hiireratas suumib. Lõuendi paremas alanurgas on ka suuminupud. Salvestatav PNG hõlmab jooniseid ja seda vähendatakse vajaduse korral, kuid projektifail säilitab joonte täpsed koordinaadid. Topeltklõpsuga saab malli teksti muuta. Failid salvestatakse samamoodi nagu käsitsi joonistatu.
- **Ainult pliiats** (pliiatsi ikoon tööriistaribal) on vaikimisi väljas. Sisselülitatuna saab lõuendile joonistada ainult puutepliiatsiga: hiireklõps valib joonise, Shift+klõps lisab valikusse, tühjalt kohalt hiirega lohistamine valib mitu joonist ja valitud jooniste lohistamine liigutab neid koos. Hiire topeltklõps lisab teksti või avab olemasoleva teksti; Ctrl+Enter lõpetab teksti, Escape tühistab muutmise. Delete/Backspace eemaldab valitud joonised. Puudutus ei joonista selles režiimis. Pliiatsi parema klõpsu nuppu hoides aktiveerub ajutiselt valikutööriist; vabastamisel taastub eelmine tööriist. Kui hoiad selle nupuga pliiatsiotsa objektil umbes 0,7 sekundit paigal, tekib üks 24 px võrra nihutatud koopia (grupp või mitmikvalik kopeeritakse koos). Liigutamine alustab tavalist lohistamist ja tühistab pika vajutuse; Ctrl+Z võtab koopia tagasi. Pliiatsi eraldi kustutamissignaal (sh tagumise otsa eraser-signaal) kustutab endiselt. Lüliti jääb meelde. Väljalülitatuna saab hiirega jälle joonistada (valimiseks kasuta valimistööriista).
- **Autosnap** (magneti ikoon, vaikimisi sees) haagib uue ristküliku serva olemasoleva ristküliku külge, kui servad on kuni 18 px kaugusel ja püstised/rõhtsad ulatused kattuvad. Läbi ristküliku tõmmatud sirge otsad haagitakse selle välispiirile, kui otsad on piirist kuni 26 px kaugusel. Otseste kujunditööriistade korral näed haakumist juba lohistamisel. Pliiatsiga tehtud kuju haagitakse pärast automaatset kujundituvastust pliiatsi tõstmisel. Samuti saab olemasolevate ristkülikute servade vahel joonistada L-kujulise osalise ristküliku (isegi kui kasutatavad servad kuuluvad eri ristkülikutele), või ühe ristküliku serva juures U-kuju: olemasolevad servad moodustavad puuduva külje või küljed. Ka ristküliku sees serva lähedale joonistatud uue ristküliku serv haakub sellega. Magnet ei muuda vabakäekritseldusi ega markeri tõmbeid (Automaatkujud sirgendab eraldi lahtised pliiatsitõmbed). Magnet on eraldi väljalülitatav ning jääb meelde.
- Vasakul asuvas **jooniste failipuus** saad luua lehti (nt „Sisselogimine”), lisada nende alla alamlehti (rea `+`, nt „Avaleht”), kopeerida lehe joonistuse selle lehe alamleheks (kopeerimisikoon; koopia ilmub failipuus algse lehe alla ja haru avaneb automaatselt), muuta nime (topeltklõps või F2), avada/sulgeda haru ning kustutada lehte koos alamlehtedega. Iga lehe joonistus ja tagasivõtmise ajalugu on eraldi. Lehe nime ees olev märkmeikoon avab selle lehe märkmed; tekst salvestub automaatselt koos projektiga ning lehe kopeerimisel kopeeritakse ka märkmed.
- Päikese/kuu nupust saab valida **heleda või tumeda teema** (sh terminal); valik jääb meelde. Heledal lõuendil on põhijoon must, tumedal kuvatakse sama joon valgena. Teema vahetus ei muuda jooniste algseid värve projektifailis, kuid uuendab salvestatud PNG-d.
- **F11** lülitab kogu rakenduse täisekraani ja tagasi (ka siis, kui fookus on terminalis).
- Failipuu ülanurga noolega saab selle õhukeseks ribaks peita ja uuesti avada. Terminali päises on samasugune peitmise nool; paremal ribal olev nool avab terminali uuesti. Nende vahel olevat vertikaalset eraldajat saab lohistada terminali laiuse muutmiseks (klaviatuuril nooleklahvidega 20 px samm). Seaded jäävad meelde; terminaliprotsess jätkab ka peidetuna tööd.
- Muudatused salvestatakse automaatselt ~450 ms pärast viimast muudatust. Pane tähele: pooleli olevat tõmmet ei salvestata enne pliiatsi tõstmist. Esimesel avamisel võetakse vana üksikjoonis automaatselt esimese lehe sisse.
- Terminali saab teksti kleepida **Ctrl+V**, **Ctrl+Shift+V**, **Shift+Insert** või paremas servas oleva kleebiikooniga. Valitud terminaliteksti kopeerib Ctrl+C; valikuta Ctrl+C katkestab jooksva käsu. Kleepimine kasutab Windowsi lõikelauda ega saada teksti automaatselt Enteriga. Kui lõikelaual on pilt, salvestatakse see projekti `attachments/clipboard-….png` faili ja terminali kleebitakse selle failitee; Claude saab pildi sealt lugeda. Pildifailid jäävad projektikausta ka pärast rakenduse sulgemist.
- Parempoolne terminal avaneb projekti kaustas. Seal saab käivitada PATH-is oleva AI-agendi, näiteks `pi`. `project.json` sisaldab kogu failipuud ja jooniseid, `pages/<id>.png` / `.json` on iga lehe failid ning `canvas.png` / `.json` tähistavad parajasti avatud lehte. Terminal avaneb automaatselt projekti kaustas; selle asukoha nägemiseks kasuta terminalis käsku `pwd`. Rakendus loob sinna `CLAUDE.md` ja `AGENT-API.md` juhised (olemasolevaid ei kirjuta üle), et Claude Code oskaks lugeda joonistust ning lisada, asendada ja eemaldada aktiivse lehe objekte `agent-inbox/*.json` käsufailidega. Rakendus võtab käsud lõuendile koos Ctrl+Z ja autosalvestusega; tulemused kirjutatakse `agent-results/` kausta. Lähtekoodiprojektil on eraldi `CLAUDE.md` kooditöö jaoks. Juba avatud Claudele ütle „Loe CLAUDE.md”; uue sessiooni alguses loetakse juhis automaatselt.
- „Ekspordi PNG” laadib pildi eraldi alla. Projekti automaatsalvestus on sellest sõltumatu.

Terminal on päris kohalik shell ja selles käivitatud programmidel on sinu kasutaja õigused. Käivita ainult agente ja käske, mida usaldad. Agent ei näe rakenduse ekraani otse: ta loeb salvestatud pilte ja projektifaile ning saab joonistust muuta üksnes eraldi `AGENT-API.md` kirjeldatud käsufailide kaudu. Enne järgmist käsku kontrolli alati `agent-results/` vastust. MVP kasutab ühte mitmelehelist kohalikku projekti ega sisalda pilvesünkroonimist.
